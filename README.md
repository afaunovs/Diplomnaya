# Diplomnaya
Моя дипломная работа по распознаванию лиц
В проекте используется библиотека face_recognition_python
Что он может ?
распознавание лиц по: 
-обученной модели;
-изображению загруженное как исходник;
-сравнивать загруженое изображение с исходником или обученной модели (dataset);
Dataset подготавливается отдельно или в самой же программе, а также он может быть в расширении .pickle
